# Building agents just got simpler: Introducing the new Agent Studio

_Published 2025-07-01 — [Original post](https://toolhouse.ai/blog/building-agents-just-got-simpler-introducing-the-new-agent-studio)_

Building agents just got simpler: Introducing the new Agent Studio Today, we're announcing the biggest update yet to Agent Studio. We are taking away the complexity of building agents, drastically simplifying development and deployment for everyone. Jul 1, 2025 2 minutes Daniele Bernardi Agent Studio isn’t just a playground for prompt tinkerers—it’s where app development meets prompt engineering.

— Fabio Pulvirenti, CEO of Etiqa (Toolhouse Agency Partner) Today, we're announcing the biggest update yet to Agent Studio. We are taking away the complexity of building agents, drastically simplifying development and deployment for everyone. Solving a problem for the entire industry Agent Studio is the culmination of months of user feedback and research. Understanding where users struggle in their agentic development workflow has been key in our development process.

We asked people using other tools or platforms to describe where they were encountering difficulties. A few unmet needs clearly emerged: Users struggle with creating working prompts for their agents. No platform has solved for this in a satisfactory way. This is a common pain regardless of the skill level. In other words, both engineers and vibe coders face the same issue when it comes to prompting.

When users can’t get their agent working, they blame the platform, not the prompt. Users feel frustrated because building agentic apps end-to-end is still a multi-step process that is too hostile to the average user. From what we heard, no single solution out there has fully addressed this problems. Until today. What We've Built The new Agent Studio puts your agent configuration front and center.

Here's what we changed. Built-in prompt engineering: Simply explain in your own words what your agent should do. Agent Studio will automatically translate your ask in a fully fleshed out Toolhouse agent file. Agent Studio is powered by an agent that’s trained on effective prompt engineering techniques. We used over 200,000 real Toolhouse agent runs to train this agent.

And as you might expect, our Agent Studio agent is built and hosted on Toolhouse. Side-by-side configuration editing : Your Toolhouse Agent YAML file sits alongside the interface, giving you complete visibility and control over every aspect of your agent. No black boxes, no hidden settings. Real-time testing : Prompt and re-prompt your agent directly in the UI. See results immediately.

Iterate until it's perfect. Preview before deployment : View exactly how your agent will behave before it goes live. No surprises in production. Version control built-in : Every agent is a file, so you can put them under version control and roll back or deploy with a simple git command. Sharing and team functionality : As always, you can share public agents with your team or with other developers.

Your agents remain private by default on paid tiers. Why This Matters Every feature in the new Agent Studio serves one goal: removing friction between your idea and a working agent. By making development faster and less obscure, we’re agent development for everyone. When building agents becomes this straightforward, small teams can compete with large ones. Individual developers can solve problems that previously required entire departments.

The new Agent Studio is not just a product; it’s a commitment to keeping AI agent development accessible, transparent, and powerful.
