# Introducing MCP Discovery: Effortless Agent Superpowers in Toolhouse

_Published 2025-08-05 — [Original post](https://toolhouse.ai/blog/introducing-mcp-discovery-effortless-agent-superpowers-in-toolhouse)_

Introducing MCP Discovery: Effortless Agent Superpowers in Toolhouse MCP Discovery lets you build agents with zero setup, just write what you want Aug 5, 2025 5 minutes Homan Mirgolbabaee Say Goodbye to MCP hell We’re thrilled to announce MCP Discovery, the newest upgrade to Toolhouse that makes connecting your agents to any Model Context Protocol (MCP) server as easy as writing your idea.

Until now, connecting your agent to an MCP server meant digging through docs, piecing together URLs, guessing parameters, and hoping it all just worked. It rarely did and we’re changing that. MCP Discovery is a new layer inside Toolhouse that removes all the setup friction. Now, when you describe what your agent should do, Toolhouse figures out what MCP servers it needs — and wires them up for you.

You just write your prompt. Toolhouse does the rest. Why This Matters Let’s be honest: configuring MCP servers has always been a pain. It’s confusing, error-prone, and often requires a lot of trial and error. With MCP Discovery, all that friction disappears. Now, when you build an agent in Toolhouse, the right MCP servers are detected and configured for you automatically and securely.

You get the power of advanced integrations, without the hassle. How It Works Build any agent in Agent Studio (You describe what you want your agent to do) Toolhouse scans your prompt and it matches your use case to the correct MCP servers The necessary connections appear automatically, no manual setup required! Just provide your service credentials (like a Notion public URL or a Supabase Token) and you’re good to go You can at any time override or customize settings — but you don’t need to.

It just works. A Real-World Example Imagine you want to build a virtual engineering manager that reads Notion docs and creates Linear tickets for your team. In the past, you’d have to: Find and configure both Notion and Linear MCP servers Input & double-check all the URLs and parameters Cross your fingers that it actually worked and you didn’t miss any steps Now with MCP Discovery, you just describe your agent: “build a virtual engineering manager who reads a notion page the user will provide and creates a bunch of linear tickets from it” Toolhouse automatically detects the right MCP servers, connects them.

Your agent is ready to go — no technical deep-dives required. Where to Find It MCP Discovery is available now in Agent Studio. Just start building an agent, and you’ll see the magic happen. Whether you’re a developer or a vibe coder, you’ll love how much easier it is to give your agents real-world superpowers.
