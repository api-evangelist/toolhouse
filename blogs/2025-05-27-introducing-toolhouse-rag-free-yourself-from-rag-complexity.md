Introducing Toolhouse RAG, the most seamless RAG pipeline in the industry We are rewriting the history of RAG by bringing the most straightforward developer experience possible: just one command ( th rag ) allows you to upload, chunk, embed, and store your private knowledge into a serverless vector database. Toolhouse RAG is available to any agent you build in Toolhouse. There is no need to build custom integrations. There's no need to believe us: just check out the docs to find out! One Command, Complete Freedom Toolhouse RAG supports the most common file formats right out of the box. Upload any text-based file, like CSVs, rich text files, code, and PDFs. We will add more file formats soon, and we will support larger files as well.

Using Toolhouse RAG is simple. It all starts from the th rag command: th rag create creates a RAG folder. You can create multiple folders. Use th rag add to add one or more files to your folder. You can assign the same file to multiple folders. Reference your rag folder by adding rag: (folder name) to your th file. That's it. Configure multiple logical vector stores to group together all the files you uploaded.

This way, each agent can connect to a specific vector store while keeping files in one place. For example, if you're building a marketing agent, you can have a vector store with copy guidelines, and another vector store with product data. You can upload files into these two stores independently, and connect them to one or more agents.
