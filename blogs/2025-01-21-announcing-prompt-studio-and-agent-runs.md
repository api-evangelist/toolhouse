Introducing Prompt Studio Prompt Studio is the easiest way to build AI agents, a platform designed to make every step of the process intuitive and efficient. Why Prompt Studio With Prompt Studio, you can create your agents in plain text and automatically extend them with Toolhouse tools.

These tools are built specifically for AI use cases and are preloaded each of your agents. You are always in control, so you can select the specific tools you want your LLM to use. Collaboration is seamless with Prompt Studio. Share your prompts with your team to streamline debugging and gather feedback effortlessly. This ensures your agents are optimized for real-world applications.

Prompts Studio chats can be made public or private. You can also clone existing chats; this is useful to create multiple versions or revisions of your agents without losing track of its history. To see sharing and cloning in action, check out this sample Prompt Studio agent . To top it all off, you get 500 free execution credits monthly and unlimited free premium LLM token usage to experiment and deploy your AI agents without worrying about costs.

Dive into the experience and try an example now: Toolhouse Prompt Studio . Introducing Agent Runs Building and deploying agents as APIs has never been easier. With Agent Runs , you can automatically turn any Prompt Studio chat into an agent you call via an API. These agents and their APIs are hosted on the Toolhouse infrastructure. Just like Prompt Studio, you get unlimited free premium LLM tokens .
